# Инструкция администратора — «Вместе растём»

Краткий гид для сотрудников, которые ведут сайт через админ-панель.

## Вход

1. Откройте `/admin/login`.
2. Введите email и пароль, выданные администратором.
3. Забыли пароль → `/admin/forgot-password` (письмо придёт, если в Supabase настроен mailer).

Роли:

| Роль | Доступ |
|------|--------|
| **admin** | Весь контент + **Настройки** (контакты, название клуба) |
| **editor** | Программы, события, новости, альбомы, документы, заявки, членство, команда |

## С чего начать после запуска

1. **Настройки** (`/admin/settings`, только admin) — заполните контакты, которые можно показывать публично. Пустые поля на сайте не появятся. Не пишите «НУЖНО ЗАПОЛНИТЬ» в публичные поля.
2. **Команда** (`/admin/team`) — ФИО и роли педагогов; публикуйте только согласованные биографии.
3. **Программы** и **События** — основной контент календаря.
4. **Юридические страницы** `/privacy` и `/consent` — замените тексты-заглушки на утверждённые документы (через правку кода или позже отдельный раздел).

## Как публиковать контент

Общий принцип: **черновик → проверка → published**.

| Раздел | URL админки | На сайте |
|--------|-------------|----------|
| Программы | `/admin/programs` | `/programs` |
| События | `/admin/events` | `/events` (календарь) |
| Новости | `/admin/news` | `/news` |
| Фотоальбомы | `/admin/gallery` | `/gallery` |
| Документы | `/admin/documents` | `/documents` |
| Членство (тарифы) | `/admin/membership` | `/membership` |
| Заявки | `/admin/applications` | — (только сотрудники) |
| Команда | `/admin/team` | `/about` |
| Настройки | `/admin/settings` | футер, `/contacts` |

### События (важно для календаря)

- Укажите **начало и окончание**, часовой пояс, статус регистрации.
- `published` + регистрация `cancelled` — событие **остаётся видимым** в календаре как отменённое.
- После публикации сразу смотрите `/events`.
- Вместимость учитывает подтверждённые заявки (остаток мест).

### Фотоальбомы

- Допустимы **JPEG, PNG, WebP** (не HEIC) и видеофрагменты **MP4, WebM**.
- В подписях и именах файлов **не указывайте имена детей**.
- Задайте обложку альбома кнопкой «В обложку» (только фото, не видео).

### Документы

- Только **PDF** и **DOCX**.
- Черновики не видны посетителям.

### Заявки

1. Новые заявки — статус `new` на обзоре `/admin`.
2. Откройте карточку, свяжитесь с семьёй, поставьте статус (`contacted`, `confirmed`, …).
3. Заметку менеджера видят только сотрудники.
4. Список можно выгрузить в CSV.

## Тексты без выдумок

На публичный сайт **нельзя** выносить непроверенные:

- телефоны, адреса, цены, биографии, юридические формулировки.

Если данные ещё не согласованы — оставьте поле пустым или держите запись в `draft`. Служебная пометка «НУЖНО ЗАПОЛНИТЬ» на сайт не выводится.

## Медиа

| Тип | Форматы | Лимит (примерно) |
|-----|---------|------------------|
| Обложки и фото | JPEG, PNG, WebP | 10 МБ |
| Видеофрагменты в альбоме | MP4, WebM | 50 МБ |
| Документы | PDF, DOCX | 20 МБ |

## Частые вопросы

**Почему на сайте пустой блок?**  
Нет опубликованных записей или поля пустые — блок скрывается специально.

**Как добавить редактора?**  
Только через Supabase Auth + запись в `profiles` (см. [DEPLOY.md](./DEPLOY.md)). Из админки пользователей создать нельзя.

**Календарь показывает не тот месяц?**  
Проверьте даты события и `CLUB_TIMEZONE` / поле timezone у события.

**Заявки не приходят на почту?**  
Уведомления опциональны (Resend / Telegram). Заявки всё равно сохраняются в `/admin/applications`, если настроен `SUPABASE_SERVICE_ROLE_KEY`.

## Безопасность

- Не пересылайте пароли в мессенджерах без необходимости.
- Не публикуйте `service_role` ключ.
- После увольнения сотрудника отключите его в Auth и поставьте `is_active = false` в `profiles`.
